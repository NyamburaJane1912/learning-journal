# Session-1

In this session I got an introduction to web development.

## Git and GitHub
Git is a version control system that tracks every change I make to
my code. GitHub is the online platform where I host my Git
repositories and collaborate with others.

## VS Code
VS Code is the editor I use to write code. Extensions add extra
features, like Git integration and smarter code suggestions.

## Live Server
Live Server is an extension that shows my changes in the browser
instantly and refreshes the page when I save.

## Localhost
Localhost (127.0.0.1) lets my computer act as a test server, so I
can try out my website before putting it online.

## Frontend and Backend
The frontend is what users see (HTML, CSS, JavaScript). The backend
is the server logic and database behind it.

## Frameworks
Frameworks are pre-built structures that speed up coding.
